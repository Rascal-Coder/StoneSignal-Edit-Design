# Art sources and references

Verified 2026-10-06.

Current runtime meshes and icons are original Blender MCP geometry and renders from `create_stonesignal.py`, commissioned for StoneSignal. The user-provided screenshot supplied the stone ruin / cyan crystal / warm core visual direction. No screenshot pixels were extracted into runtime assets.
